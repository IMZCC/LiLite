# 当前界面的布局预览

在 Windows 执行 `Native\Tools\Previews\render.ps1`，按源码中的页面结构、导航和控件顺序生成本地 HTML 与 PNG，产物写入 `Native/dist/Previews/2026-11-13`

这是源码对照的布局预览，不是 SwiftUI Preview、iOS 模拟器或真机截图。系统字体、控件及材质由 CSS 近似；视频、封面、账号、计数均为本地示例数据。页面不会读取凭据、登录用户账号或发送业务请求

`provenance.json` 记录每页对应的 Swift 文件及内容摘要，便于重新对照。首页遵循主推荐与后续双列网格、系统标签栏及独立搜索，详情遵循播放器、进度、简介/评论、元数据及次要选项入口的实际次序；我的页和设置页保持实际分组顺序。另提供深色首页及横向全屏播放预览

这批预览展示当前 iOS 27 的默认布局。应用源码实际采用系统 `Tab` / 独立搜索页，以及自定义播放控件的 `glassEffect` / `GlassEffectContainer`，浏览器图只能示意玻璃材质和控件位置；旧 iOS、显式自定义导航及“降低透明度”另有原生兼容分支
