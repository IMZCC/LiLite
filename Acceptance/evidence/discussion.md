# 评论、对话与内容引用

对照固定上游 lib/grpc/reply.dart、lib/pages/common/reply、lib/pages/video/{reply,reply_reply,reply_new,reply_search_item}。6 个服务使用固定版本的上游 protobuf 描述生成 Swift 模型

主评论会合并置顶评论并按 ID 去重；楼中楼保留根评论，通知和楼内预览将目标 rpid 送入定位请求，列表在内容载入后滚动到目标。热度和时间分别支持主楼、二楼的默认排序，精选列表使用服务器标题。折叠入口携带服务器原有的分页对象；有对话编号的回复可单独查看对话。翻译只按相同 rpid 取 translatedContent，仍可切回原文。带货、提及、简介、作者和关键词规则也用于新接口

评论编辑器可查询视频和专栏。标题插入当前光标，未编辑的内容引用在提交时转为服务提供的网址；编辑标题后作为普通文本处理。评论保持已有的图片、表情、提及、点赞、踩、回复、置顶与分享功能。番剧对照稿件 aid/type 1，课程对照课时 epId/type 33。评论返回手势可分别从两侧边缘触发，返回按钮一直可用

已用公开稿件 170001 做匿名只读检查：MainList 返回 20 条及下一页，DetailList 含根楼共 21 条；切换排序后带目标 rpid 再查仍命中指定子楼，DialogList 返回 20 条。四次运行均观察到 HTTP 200、gRPC 0。该样本未返回折叠卡，折叠对象携带与去重、同名标题的不同链接、译文定位等用独立的序列化输入验证。未向线上提交评论或进行其他账号写操作
