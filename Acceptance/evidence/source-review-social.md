# 资料、关注、笔记与已有功能复核

| 上游能力 | 原生操作和核查结果 | 还需要验收 |
|---|---|---|
| 头像、昵称、签名、性别、生日 | 账号页和本人空间均可进入 ProfileEditor。打开前读取服务资料；只更新所选项，昵称费用需要确认。AvatarEditor 稳定生成裁切数据，调用独立头像接口 | 真机相册、费用提示及登录状态的错误反馈 |
| 移除粉丝 | 本人粉丝列表的侧滑或长按菜单显示姓名并要求确认；请求 act=7、re_src=11，限定发起账号，成功后重载。查看他人的粉丝时没有此操作 | 账号切换与列表交互 |
| 视频笔记 | 原版 video/note 的写作入口是官方 h5/note-app；原生笔记列表可从已登录账号在 WKWebView 打开对应 oid，传递互动视频标记。未发布笔记可在隔离账号的站内网页继续打开。仅该域名、该稿件且主文档的用户点击能触发返回视频或显示完成按钮 | 只读实测稿件 170001 的页面 HTTP 200、标题“笔记”；已登录草稿保存与发布留给实际使用 |
| 私信设置和折叠消息 | IMSessions 识别 foldID，打开对应类型的下一层列表；IMPreferences 对服务返回的设置逐项读取并提交所选取值 | 账号权限、折叠会话和修改持久化 |
| 搜索用户动态、查看用户图文 | 空间搜索走 feed/space/search 并携带 UID、页码与字符串 offset；图文投稿支持类别和文集。图文服务的公开账号实读见 dynamic-protocol.md | 区分空结果、网络失败与账号可见性 |
| 弹幕合并、跳过番剧片头片尾 | 弹幕规则合并相邻的相同文本，绘制重复数。片头片尾依据服务提供的 OP/ED 区间及用户模式，区间边界和单次行为有主机检查 | 播放器实际画面与用户拖动后的体验 |
| 课程收藏、追番追剧收藏、音乐相关视频 | Courses 区分已收藏列表和课程目录，单项详情可收藏或取消；FollowedSeasons 按追番/追剧与观看状态分页；音乐详情能打开音乐相关视频、逐页跳转到稿件 | 列表操作后返回刷新、登录态与真机导航 |
| 屏蔽带货动态/评论、黑名单作者视频 | DynamicEntry 同时读取当前动态及原动态的带货标识，评论过滤检查链接元数据与前缀；推荐规则先检查作者黑名单，再执行关注豁免 | 跨列表覆盖、特殊服务格式 |

以上对应入口原先有几条仍在索引里记作待开发。现补上具体 Swift 路径并保留部分完成状态；本次复查没有对任何线上资料、笔记或粉丝执行修改
