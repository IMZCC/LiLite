# 举报与本机屏蔽

原版 lib/common/widgets/dialog/{report,report_member}.dart、lib/http/{member,reply,user}.dart 和 PageUtils.reportVideo 定义了不同对象的入口和服务格式。原生版从视频更多菜单、他人动态、评论菜单和 UP 主空间提供对应入口

评论支持分类原因和补充描述，“其他”和“虚假不实信息”必须说明；可一并加入黑名单，或选择仅在本机屏蔽。动态举报和加入黑名单是两个独立的请求；举报成功后拉黑失败时，仅重试拉黑。用户资料举报支持勾选头像、昵称、签名和可选原因；space 接口以 status 布尔值判定成功。视频举报与原版一样打开站内官方申诉页

提交前验证当前账号与打开表单时一致。视频菜单及可替代的用户、评论网页使用现有站内网页账号隔离。日常构建和离线检查不会产生真实举报、拉黑或平台处罚。最终设备验收检查表单交互和账号切换，不以举报真实无关内容作测试
