# 直播 CDN 偏好

基线 lib/pages/setting/models/video_settings.dart 和 lib/utils/video_utils.dart 的 getLiveCdnUrl：替换所选线路的主机前缀，保留本场直播返回的 base_url 与 extra。原生应用默认直接使用直播间给出的地址，也可在「网络连接 → 直播 CDN」填写 HTTPS 地址或主机，含端口或前缀路径均可。界面说明自定义主机会收到临时播放参数，未设置时不会访问自定义主机

每条线路先尝试显式配置的源，失败后尝试同一条官方地址，再轮换备选。菜单显示当前实际主机及服务提供的画质；格式偏好与 CDN 偏好独立备份。不会给媒体请求添加账号 Cookie。主机测试验证参数中的百分号转义保持原样，拒绝凭据、查询串和路径穿越，按用户选中线路排序。未将任何真实播放参数发送给自定义站点，真实直播性能和切换仍待设备验收
