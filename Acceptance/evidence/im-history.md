# 私信记录、翻页和消息呈现

按固定上游 lib/grpc/im.dart 的 SyncFetchSessionMsgs 与 lib/pages/whisper_detail 的会话行为移植。已绑定移动授权的单聊使用对应账号的 RPC，网页账号及群聊使用原有 Web 接口。请求使用 20 条一页、talker 和 end_seqno，逐页合并服务返回的表情字典。没有登录、切换账号或取消请求时不会把旧数据送进新会话

显示顺序为旧到新，打开定位到最新消息；上翻读取更早的消息时保留原位置，发送或刷新后合并相交窗口，若两页之间存在缺口则按新的游标重新加载。支持文本与网址、会话表情、图片、分享卡、通知链接、视频和专栏卡、多条目卡与消息提示；撤回控制记录不当作消息展示，已撤回的卡片或正文不提供跳转。读取有效消息后才更新已读，单独的陌生人发信提示不确认；撤回及举报均再次绑定原账号和消息标识

使用本地固定请求帧及响应检查移动请求路径、设备字段、游标、64 位消息键、表情、已撤回标记。主机检查分页相交与断档、重复消息、字典表情、第二个通知链接及提示 JSON。协议源码可从 570 项固定描述符复现；WSL arm64 Release 及主机回归通过。未访问真人会话或发送、撤回、举报真实消息；登录后的收发与真机滚动留待完整验收
