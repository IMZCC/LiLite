# 视频详情与播放器核查

[逐项清单](archive-detail-signoff.json) 覆盖固定版本的 page:video、18 个 screen:video 子页、/videoV、/playSpeedSet 和 plugin/pl_player；76 份上游 Dart 源文件记录了规范化 LF 后的 SHA-256。另列 32 项直接影响详情、记忆、倍速和选集的设置；输入和全屏的 88 项另见 [按键与手势](player-key-gestures.md)

| 核查内容 | 原生行为 |
| --- | --- |
| 简介、稿件与相关 | 显示 BV、AV、标题、争议信息、发布日期、赞/币/收藏/分享数、充电与互动视频标志、服务实际返回的全片空降类别。BV/AV 和标题可复制。富文本简介处理账号提及、公开站内链接、时间点和标签；相关推荐按推荐角色加载，可过滤、移除卡片和重载。前台可见的同时观看人数每 10 秒更新，切 CID/角色或离开页面即取消 |
| UGC/PGC 互动 | 稿件关系读取点赞/点踩/已投币/收藏。点踩使用当前主账号自身的移动授权，收到回执后清除互斥的赞；番剧不会调用 UGC 点踩。投币窗口给出当前稿件上限、已投数、能读到的本人余额，可选同时点赞；按确认才发送。稍后再看菜单与快捷键共用按账号和 aid 区分的回执，支持加入与移除。主站没有提供的移动授权不会由客户端猜测 |
| 分 P、合集与记忆 | 小屏/侧栏能切分 P，在合集里可展开单条稿件的多个 P 并精确打开相应 CID。逆序、切到反转后第一集和播放全部的限制保持原意。未指定起点时打开首 P；继续观看上一 P 是四秒提示，仅在点按后切换。指定分 P/时间、列表的起点优先；同一 CID 可以恢复服务进度。原文位置 lib/pages/video/controller.dart 的 continuePlayingPart 与 block_mixin.dart 的四秒列表计时 |
| 分享 | UGC 的普通链接包含非第一 P 的 p；精确分享带毫秒精度 t。番剧与课程各用自己的 ep 深链。进入系统分享、复制普通/当前进度链接、打开其他应用与既有站内分享均有入口。链接只含公开作品定位，不传取流 URL 或账号授权 |
| AI、分段 | AI 摘要、章节提纲和时间戳取自服务，换 CID 或读取角色后旧响应失效。分段读取 type 2 和 imgUrl，展示封面、起止时间及当前段。临时的“进度条显示分段”同时控制内嵌和全屏标记；点章节跳转，保留全局 showViewPoints |
| 本地播放和速度 | 缓存入口按视频账号过滤已完整保存的内容，播放中可打开目录、看封面、定位当前项、选择任意其他项。按默认倍速进入，切同一队列的下一项保留当前速度。倍速设置的“重置列表”只恢复预设列表，不重置用户默认/长按速率 |
| 播放信息和重载 | 普通稿件、番剧/课堂和离线有播放信息：真实输出格式、音频采样率/声道、当前分辨率、进度、倍速和来自 AVPlayerItemAccessLog 的可得统计。在线可重载服务给当前账号/CID 的最新视频和音轨信息，保留时间并按新授权选择可用质量 |
| 编辑播放地址 | 服务提供的 DASH 音/视频或渐进备线在当前播放授权中逐轨匹配，可在原播放器切换。用户输入独立 HTTPS 媒体时打开独立播放器，不借用稿件账号、媒体时长或观看历史。普通模式可播独立视频或将匹配的音轨/画面按各自 timeRange 组合；要求软件解码时，支持受支持的经典 MP4/M4A，通过各自的样本表和有限 HTTP Range 读取生成本地回放。加密轨道、跨源挪用当前取流签名、服务来源混用均不接受 |
| 既有子域 | 笔记、主评论和楼中楼、评论内容搜索、发送弹幕、UP 侧栏、媒体列表、PGC 目录、缓存面板及空降投稿均在逐项清单中链接到对应实现及独立验收。系统 PiP、外部投屏、视频时钟、解码、缓冲、着色器、弹幕/字幕以功能域报告为准；Windows 桌面置顶窗口及 Android 的设备传感器参数不是原版 iOS 功能 |

执行 bash Checks/archive_detail.sh：读取合成回包检查章节解析、分 P 续看须由用户确认、稿件/课程精确链接、点踩/三连状态、逐轨媒体授权及跨源拒绝。真实 FFmpeg 合成 96×64 H.264 视频和独立 48 kHz AAC 文件，使用原生 MP4 样本表代码分别重新组装 fMP4，再解码；YUV 与 PCM 的 SHA-256 分别等于两份原始输入。无外部网络和真实账号写入。按键、手势专项仍运行 Checks/player_keys.sh

最后的真机清单：会员/课堂/多音轨取决于实际账号授权；系统输出、播放 URL 过期后重载、第三方播放器互跳、外接键盘以及真实全屏/画中画的交接由 iPhone 验收。没有为测试扣币、移除收藏、提交空降/弹幕或修改用户历史。服务未提供的授权、解码器不接受的独立媒体或无法组合的流式音轨会提示播放失败
