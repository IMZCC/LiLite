# 真机反馈后的详情与内容页布局修复

基线 `2d16f01f5`，真机为 iPhone 15 Pro Max / iOS 27.3，本轮只处理 SwiftUI 布局和页面生命周期，不改签收门、功能清单或签名安装

已实读 `dist/DeviceTools/home-before.png`（1290×2796，恢复中的视频详情，并非首页预览图），随后逐条追到实际 Swift 页面和子面板

## 实际问题与修复

| 触发路径 | 实际代码问题 | 本轮修复 |
| --- | --- | --- |
| 视频详情已经就绪，播放器底部细进度条出现 | `Theater` 自带进度和播放控件，`PlaybackPanels` 又无条件放第二套进度/播放/全屏行，真机图明确出现两层 | 播放就绪后由播放器自己的原控件统一处理；未准备或延迟启动时仍保留外置启动行 |
| 竖屏、打开全屏侧面板或大字号 | 播放、进度、时间、超分、缩放复位、PiP、全屏全部挤同一行，滑条可以被压得几乎无法拖动 | 小于 600pt 或辅助字号时将进度与操作分行，操作可自动换行；保留全部原回调，主要触点至少 44pt，字幕预留相应控件高度 |
| 全屏打开工具面板，视频区域随之变窄 | 顶部锁定、赞币藏、工具、截图、时间轴、退出仍固定一行 | 顶部操作按可用宽度换行并右对齐，锁定和退出始终保留 |
| 视频详情与课程/番剧信息页 | 多个操作行依赖压缩文字来容纳图标、投币、收藏、投屏及菜单，真机图出现不正常换字 | 新的 `WrappingActions` 原生 Layout 根据实际文字尺寸换行；赞币藏与次级操作分组；课程、番剧、普通视频均保留完整动作 |
| 查看视频标题、切换下一视频 | 标题缺少垂直优先级，详情区复用同一个滚动容器 | 标题使用完整垂直尺寸；信息滚动区按视频来源独立标识，新的来源从顶部开始，详情内容改为惰性竖排 |
| 播放选项表单 | 原线路按钮使用 iconOnly，放入表单后缺少可见的行名称 | 表单显示“视频线路”，仍调用原线路按钮及完整面板 |
| 直播正常页旋转、弹出键盘 | 固定视频比例会在高度变少时继续占用大量空间；直播操作最多八项挤成一行 | 非全屏视频高度同时受可用高度限制；直播操作换行，聊天室继续取得剩余空间；真正全屏仍按实际剩余区域填充 |
| 播放页显示自己的选项、弹幕列表、聊天等面板 | 部分系统紧凑呈现可能使底层页面走 onDisappear，原逻辑立即停止播放和直播聊天 | 自己的面板显示期间不执行离页停止；真正离开且没有自己的面板时仍执行原清理 |
| 搜索结果分类与筛选 | 标题/计数与“筛选”文本竞争狭窄宽度，横向边距也与列表不一致 | 保留原分类菜单和筛选表单，筛选按钮用 44pt 图标触点，统一边距；滚动列表可交互式收起键盘 |
| 搜索 Tab 根页（`dist/DeviceTools/search-before.png`） | 真机只有热搜和打开链接，缺少文字输入；searchable 原挂在导航内部的透明内容 Group | 保留全部私有搜索状态，将 searchable、候选、提交与输入任务整串封装后挂到导航容器边界；embedded 方式保留原宿主导航，不只迁移字段而遗漏提交事件；新 SDK 包需真机确认输入框、键盘和提交 |
| 搜索 UP 主结果的投稿横排 | 无高度约束的 LazyHStack 被放在自适应列表行内，横排无法提供可靠的垂直本征尺寸 | 这段短投稿列表采用可测量的 HStack，并让横向容器使用内容高度，保留原视频链接 |
| 从文件提供方导入搜索历史 | 在 UI 回调中同步读取文件，远程文件或大文件会卡住界面 | 安全作用域与有上限的读取放到后台，仍走原 8MiB 及 JSON 验证和保存逻辑 |
| 长专栏/图文正文 | 整篇正文在一个普通 VStack 中一次创建 | 正文段落改为 LazyVStack，内容、链接、图片打开和评论分栏路径不变 |
| 动态/图文操作栏及动态 UP 面板大字号 | 动态最多八项动作固定一行；UP 顶部和侧轨始终是 74/68pt | 动作栏按实际内容换行，UP 轨道通过 ScaledMetric 跟随字号，避免名字和控件被定高切断 |

`WrappingActions` 只改变布局，不更换按钮的身份、网络发送、确认、弹出面板或账号绑定；宽度变化时保持同一组布局子视图

## 本轮实际复核的入口

- 普通视频：封面/延迟启动 → 播放 → 进度拖动 → 全屏 → 工具侧面板 → 返回详情；核对画质、倍速、重复、会话设置、线路、音轨、音质、字幕、截图、AirPlay、音量、弹幕列表与错误重试的原消费者
- 视频信息：标题和 BV/AV 复制、简介、作者、分 P/合集、听视频、待播、赞币藏、投屏、更多菜单、评论与相关推荐
- 番剧/课程：共用播放区域、分集信息操作、试看、缓存、字幕、线路和剧集列表，确认普通视频的自适应修复也覆盖其共用容器
- 搜索：独立 Tab、sheet、默认词、历史、输入候选、UID/编号跳转、每类筛选和结果分页；保留之前的状态隔离
- 直播：目录 → 房间 → 非全屏视频/聊天室/输入 → 全屏/锁定 → 直播选项、画质、线路、音轨、截图、醒目留言、屏蔽、贡献榜和聊天面板
- 图文/动态：阅读分栏与评论容器、长正文、图片分页、动作栏、UP 主动态轨道、动态详情及编辑/转发入口
- 另外读取了 TopicTimeline、ReadingSplit、CreatorSpace/CreatorLink、CreatorOpus、ReplyReferencePicker、PGCHome/订阅及时间表、各类原生 Form/List 与 sheet 容器，未因本轮修复取消这些入口或用户定制
