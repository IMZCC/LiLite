# 弹幕与字幕：基线、验收与设备复查

上游采用 `lib/pages/danmaku`、`lib/grpc/dm.dart`、`lib/plugin/pl_player` 及视频/直播播放器控件。逐项对应见 [机器清单](danmaku-subtitles.json)，其中区分上游设置、页面/路由、独立操作和各项证据。运行 `python3 Checks/caption_manifest.py` 会比对固定设置表、仓库总表中的同域 ID 以及每项声明的具体实现，未变更总表

- **弹幕分段和展示**：已授权的移动身份可调用原版 DmSegMobile（type、oid、segment_index），访客及只有网页登录的账号使用自身网页弹幕分段接口；移动服务明确未实现时可使用同账号网页路径。根据回执解析 state=1 的关闭状态，在当前账号/CID 的发送页禁止提交。关闭弹幕和设置低负载 PiP 时不再主动加载，返回后加载当前段。服务拒绝不会再静默改走旧 XML 端点。屏上弹幕池从这一帧实际排轨的静止、滚动和高级条目读取，可刷新、复制、跳转、点赞、举报或撤回；保留整段搜索。原版对非模式 7 的内容落入普通文字分支，模式 8/9 以文字显示，不执行脚本。固定播放器没有消费答题/投票 commandDm 数据的入口
- **弹幕操作回执**：点赞与取消分别处理成功、已赞 65006、未赞 65004；仅真实状态变化调整本机计数。按固定原因表提交举报，检查业务及内层结果。用户明确勾选“同时屏蔽”时另行更新当前账号的发送者规则，若失败保留举报已提交的结果。发送前核实当前登录/视频的关闭状态、会员颜色权限，切换账号不会显示前一个账号的结果。关键词、正则、发送者、直播房间屏蔽和原版设置已在清单中逐条关联
- **字幕导入和保存**：从系统文件选择 BCC/JSON、WebVTT、SRT 或 ASS，即便本片没有服务字幕也可导入。在普通视频、番剧、课程、应用全屏和离线播放共用选择器。服务选择返回的 AI 标记与语言描述（含服务原有的听障说明）保持可见，不猜测听障身份。支持原版默认选轨策略；原版为单轨，这里还可手动选择第二条字幕。两条轨按各自的时间同步，同一时刻的重叠内容稳定排序、去重，短句结束后恢复仍在有效时间内的长句。支持保存原服务 JSON（保留返回的附加字段）、SRT、WebVTT；用户文件仅在本次播放中使用，切集与换号均隔离
- **ASS 真渲染**：固定、校验源码的 libass、HarfBuzz、FriBidi 和 FreeType 编译为 iPhone arm64 静态库，字体由 iOS CoreText 提供。视频时钟驱动逐帧渲染，支持样式、描边、移动、矢量及卡拉 OK，不把指令或图形数据当台词；后台队列栅格化，透明 RGBA 按真实区域叠在画面上。最多同时显示两个已选脚本，限制文件大小、事件数和位图大小，离开播放页或内存警告会释放渲染缓存。样式字幕保留脚本自身位置；普通文本字幕遵循应用字号、拖动和边距设置。[W3C WebVTT](https://www.w3.org/TR/webvtt1/) · [Aegisub ASS 语法](https://aegisub.org/docs/latest/ass_tags/) · [四个库的来源、许可及重新链接说明](../../MediaKit/ASS-RELINK.md)
