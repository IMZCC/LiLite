# 播放时查看评论

基线 lib/pages/video/controller.dart 的视频标签页与 defaultShowComment 偏好。普通稿件、番剧、课堂的原生视频页统一在播放器下方切换简介或评论；播放器、暂停/继续、进度和全屏操作不随下方面板拆除。当前稿件内手选面板优先，切换稿件/剧集重新按默认设置。关闭该类评论后不发起面板读取

普通视频与普通剧集使用 aid / 评论类型 1，课堂使用 episode ID / 类型 33。嵌入的是真实 Discussion，支持分页、排序、回复、举报及进入楼层，不创建第二个模拟列表。嵌入根列表不安装独立返回手势；楼层详情仍按独立页处理。集中检查代码中的播放器实例归属、切换页面生命周期、评论对象和备份字段。真机播放时切换、软键盘、设备横屏空间与层级返回留到最终验收

补核：开启默认评论时进入有效讨论区；带指定楼层的分享优先打开真实讨论，并在允许显示评论时将播放器下方面板选中评论。普通稿件/番剧的发言区用 aid/type 1，课程用课时 ID/type 33。楼层单独保存打开时的对象、类型与阅读账号；返回、换号或切到别的作品不会继续沿用上个对象的 root/anchor。带分 P/时间、剧集和课时的组合链接由 ContentContractCheck 实际走 SharedLink.parse
