# 收藏夹与稍后再看播放列表

对照固定上游 lib/pages/later、lib/pages/fav_detail、lib/pages/later_search 和 lib/pages/video/medialist。原生入口支持播放全部、从点选的某条播放、继续上次队列、切换顺序、前后翻页和显式移除。点按条目是否自动进入队列使用与原版相同的默认值。稍后再看向服务端发送 viewed=0/2、asc 和 key，分类清理需要显式确认

播放位置按账号、列表、搜索条件和服务端排序保存，以内容 ID 和原始页码定位。缺页时向服务取下一页；服务端移动或移除书签条目时重新定位。切换显示顺序不改变当前播放的 ID，跨页时忽略重复和不可播放项。播放结束由同一个 AVPlayer 项目回调处理，睡眠定时器优先。列表接续可继承全屏；清理或修改个人列表需要当前账号和确认

Checks/PortBehaviorCheck.swift 在主机实跑跨页、重复条目、不可播放项、倒序、前后边界；xtool 编译原生 arm64 应用。私人账号的收藏改动、全屏接续效果和睡眠定时器的实机表现留到整体验收
