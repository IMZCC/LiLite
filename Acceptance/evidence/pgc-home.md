# 番剧影视首页、关注和空间入口

固定上游 lib/pages/pgc/controller.dart 与 lib/pages/pgc/view.dart 把首页推荐同完整影视索引分开。原生首页采用同一组筛选字段，影视额外带 index_type=102。匿名请求两种首页分别得到 20 部作品，服务报告总数 4,279 / 12,851；页数和总数以当次响应更新。登录用户有可分页的追番或追剧横排，分类入口通往对应订阅列表

番剧首页分别读取国创、番剧的前后各六天，现在按服务的日期戳合并，保留空日期和当天标识，去除重复剧集。两次公开请求都返回 13 天并各标记 1 个今天。主机用错开的日期、重复集、缺少 episodes 的日期验证合并。可切换日期，已播且有剧集 ID 的卡片打开对应集，未播或延期作品打开整季；关闭展示后不再触发首页排期请求。完整日历仍有独立入口

原版默认不展示 UP 主小店；开启后从空间打开真实商品目录。关注列表与分组可切换“最近关注 / 最常访问”，保存上游排序索引，并在新顺序下重新从第一页拉取，普通搜索和粉丝列表不附加访问顺序。分组明确带当前账号 mid。登录账号的订阅分页、关注排序结果和设备上的导航留待最终核查
