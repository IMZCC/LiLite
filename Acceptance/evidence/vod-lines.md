# 点播线路、音轨和离线重试

固定上游的 lib/models/common/video/cdn_type.dart、lib/utils/video_utils.dart 和 lib/pages/setting/widgets/select_dialog.dart 给出 21 个选项、独立音频开关和测速样片。原生设置保留 21 个存储名称和两个开关，兼容原版设置备份。网络设置和播放器均可选线；播放器里使用当前视频作为样片，关闭面板后按原进度重新打开所选线路。全局设置使用原版指定的视频 BV1fK4y1t7hj / CID 196018899

- 普通 UPOS 镜像优先使用服务为该镜像返回的完整地址；需要切换普通镜像时只替换白名单主机，保留 path 和原始转义参数，其他格式保留服务发的地址。Akamai、运营商专用和缓存节点只使用服务分配给相应节点的地址。没返回时继续可用的原始线路，测速单独标记「样片不提供」
- DASH 解析索引、初始化片段、拖动后的媒体片段和 MP4 均使用选线。视频与音频分别排序。听视频和独立音乐曲目在条目错误或中途断流时轮换同一资源的备用地址，保留队列项、分 P、进度和暂停意图
- 下载按轨记录当前系统任务，HTTP 状态不符、内容长度不符或并非 MP4 时尝试下一地址。重试只复用同一集、所有者及媒体身份一致的完整分轨文件。系统重新启动应用后若后台任务失效，可重新向服务取得一次同版本地址；用户删除或重新添加后旧任务不得写入新记录。不将媒体临时链接或 Cookie 写入下载索引
- 单次测速每个不同地址最多 256 KiB、总时限 8 秒；只接收与所请求范围相符的 206，短文件允许到文件结尾。关闭面板会取消尚在传输的请求。已测试指定镜像、音频独立、原始签名转义、重复地址和主机绑定，Checks/vod_probe.py 以本地 HTTP 服务检查实际 URLSession 收包、拒绝不正确的 HTTP 响应及取消
- 本次公开样片的元数据请求取得声、画轨；优先测试的 3 个服务返回的视频地址均返回 HTTP 403，未获得可用于确认线上播放或测速的媒体字节。与主机回环测试分开记录；iOS 真机切线、暂停期间的断流和后台下载的系统唤醒仍需完整验收

局域网投屏也会在同一视频的签发地址间换线：以单字节范围取得总长，后续每次只接收最多 1 MiB 的完整区间；镜像总长不一致时丢弃并尝试下一条，不把媒体签名发给接收设备。主机 HTTP 夹具覆盖了拖动、主线路失败、总长变化和继续沿用有效镜像
