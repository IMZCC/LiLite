# 私信内容分享

对照固定上游 RequestUtils.pmShare 与 lib/pages/share/view.dart：稿件 5、专栏 6、动态 11、相簿 2、番剧 16 编码为消息类型 7；直播使用消息类型 14 的直播卡片。播放器、番剧、直播、文章与动态都有原生分享入口。会话内的卡片能打开对应内容，相簿按原资源 rid 查找动态。联系人按 UID 去重，最近联系人来自 ShareList，也可以从通讯录添加。可以选多人、写最多 100 字的附言；每人先发卡片再发文字，附言失败时不重发已确认的卡片

原版描述符生成 SwiftProtobuf 的 ShareList/SendMsg 请求响应。移动端授权账号走专用 RPC，普通网页登录账号走现有 web 私信发送通道。发送绑定用户在分享页打开时的账号，只有明确点发送才写入。Wire 测试用内存回包验证接收人、消息类型、方法路径和服务消息编号，未向真实联系人发送消息。主机检查覆盖五类分享卡片回读以及非法房间号，WSL 已编译 Release arm64。双账号端到端收件与附言显示列入最终验收
