# 播放器内的临时调整

按固定上游 controller.dart 与 header_control.dart 的 tempPlayerConf 分支区分设置页默认值和当前播放器。内嵌、全屏共用当前会话；弹幕开关、循环模式、后台继续播放、系统锁屏控件、手动选的视频与音频质量均通过播放会话读写。临时模式把新值留在该播放器。非临时模式只在用户实际选择且音画轨切换成功时保存对应 Wi-Fi / 蜂窝偏好，不把系统降级的结果存成偏好。直播弹幕与离线播放有各自的会话；弹幕样式、字幕样式等独立全局设置沿用原来的含义。番剧超分另按当前内容类别和同一持久化开关处理

账号切换、系统 PiP、跨分 P 以及强制断网后的真机行为仍需最终设备验收
