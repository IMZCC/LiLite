# 点播键盘、全屏控件与手势

固定对照是 PiliPlus 2.2.0.2 的 player_focus.dart、triple_mixin.dart、common_intro_controller.dart 与 pl_player/view/view.dart；逐项映射在 [JSON 清单](player-key-gestures.json)。清单的 88 行含 42 项偏好、29 条按键路径和 17 条路由、手势、焦点路径，桌面与 Android 专有行为单列。字段中的文件锚点用于复查定位，行为断言见 Checks/PlayerKeySequenceCheck.swift

| 入口 | 当前行为 |
| --- | --- |
| 普通视频 | Q 在 200 ms 前松开点赞；R 短按无动作。Q/R 按到 200 ms 预备，继续满 1200 ms 三连。中途松开、失焦或换视频取消。触屏赞按钮使用相同时间，拖出和滚动取消；VoiceOver 有独立操作 |
| W/E/T/V/G | W 读取已投数与版权上限，再选币数；E 读取当前收藏夹，加入默认夹或按原版快速取消收藏。T/V 在稍后再看来源或收到本 UID 回执后切换增删。G 只供已加载非联合投稿的 UGC UP 主；自己的账号不会关注自己 |
| 番剧、课程、直播、离线 | 番剧三连使用 ep_id，普通投稿使用 aid；课程不借用普通投稿的社会动作。直播 Q/R 重新连接，Enter 打开发送框。离线支持缓存手动标记、切集、进度、音量、速度、画面锁和截图，无在线稿件写操作 |
| Enter | 先查当前播放时钟和手动 Sponsor 区间；没有区间才打开点播弹幕输入。用户正在播放时临时暂停，关闭后仅对同一 CID、账号、播放器对象且仍位于前台的会话续播。弹幕内容须点发送 |
| 时间与音量 | 左键以 200 ms 更新后退目标，松手跳转一次；右键 200 ms 后在正在播放时临时倍速，否则松手前进。上下按下立即调 10 个百分点，继续按每 150 ms 调一次。Shift+1/2 设为 1×/2×，逗号/句点用已配置速率的相邻档 |
| 通用控制 | 空格切播放，F/Shift+F 切全屏，D 切当前会话弹幕，M 静音，S 全屏截帧，L 画面锁，方括号切上一项/下一项。锁定后可按 L 解锁或 F 退出。隐藏锁或截图按钮不禁用这两项键盘动作。Tab 和 Command、Option、Control 组合交还系统，无桌面 P 小窗口仿制 |
| 双击、滑动、缩放 | 双击画面左/右各四分之一累计快退/快进，中间一半切播放；400 ms 合并到一次 seek。纵向滑动按三等分分别调整亮度、切全屏、音量；方向比须超过 3，反向偏好生效。双指范围 0.75（可禁）至 2×，与单指 seek 分离；长按依点按弹幕偏好取 300/500 ms |
| 弹幕命中 | 单击只冻结命中弹幕的媒体时间，普通/逆向/定顶/底/高级使用原字形、位置与变换绘制。松开从冻结处继续直至该条播放结束；在冻结处也能点击、列入屏幕弹幕并操作。seek 清空旧轨迹。不把弹幕点击当开关播放控件 |
| 状态与音量控制 | 横屏可见的控件依原版给出 HH:mm 和可选电量；系统音量按钮使用公开 MPVolumeView，侧边按键、外接输出的改变由 AVAudioSession 回报。应用内按键、鼠标与滑动可调当前播放会话 0–100% 的输出，设置的 PCM 内容增益保持独立。Apple 没有公开设置系统 outputVolume 的接口，因此自定义手势不能强改整机音量 |
| 输入安全 | 只有当前可见的键盘焦点接收 down/up，系统重复事件不重复写入。离开前台、换真实 AVPlayerItem、换 UID/CID/播放角色、全屏交接、输入框获焦会取消待处理动作。弹窗期间不执行背景播放器快捷键；确认回执通知只刷新显示，不启动第二次请求 |

本轮在 WSL 运行 bash Checks/player_keys.sh，测试真实按键状态机、UGC/PGC 请求构造、投币上限、离线/直播/锁屏作用域、199/200/1399/1400 ms 边界、重复与取消、缩放和滑动阈值、弹幕暂停及恢复。另以 iPhoneOS arm64 SDK 对修改的原生界面、控制器与事件接线定点 typecheck 通过，没有向真实账号提交请求

整机验收应覆盖物理键盘焦点经过系统弹窗和中文输入法、真实投屏路线的音量滑条、外接键盘与系统快捷键竞争、触摸长按三连和滚动取消、手机及 iPad 旋转时的控件位置。这些由硬件和系统界面参与，不计为 WSL 已运行
