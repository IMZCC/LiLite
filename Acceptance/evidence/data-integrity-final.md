# 缓存迁移、账号导入与备份终核

按实际删除、恢复、首次取凭据的调用链补核，修复以下问题

- 缓存已写入新位置的索引、旧位置尚未回收时，重启后不再直接删除旧副本。迁移保存所有媒体轨道的明文 SHA-256，回收前重新检查新权威位置、完整轨道集合及摘要；目标目录缺失、拔出、轨道改动或不完整时保留旧文件。旧版没有摘要的事务须先比较两份完整副本；重新选择仍完好的旧位置可以恢复使用，错误目标稍后再清理。受限外部缓存先认证本机封装，再核对原媒体摘要
- 批量删除仍按具体下载代次确认，加入执行时的当前视频身份核查。移除旧位置、新位置和临时迁移位置各自核对；等待附件任务取消后，再核对一次身份才清理附件
- 账号 JSON 可以离线导入，但本机不接受归档自行声明的验证证明。与原本已验证会话同字节的 Cookie 和移动令牌可分别保留证明；变化的部分必须首用核对真实 UID。网页登录凭据通过隔离 Cookie 的官方 nav 校验，移动令牌通过独立、无 Cookie 的 myinfo 校验。旧安装中没有该元数据的本机登录保留原先信任状态；原生备份导出不含证明
- 八个并发首次请求共用同一次身份校验。取消、换所选账号或同 UID 换了凭据时，旧回包不能替新会话建立证明，也不能把旧账号交给新角色。批量远程登出同样经过检查；仅本机移除不需要网络校验。数据包账号角色、回滚和后置发布仍保留已有约束
- WebDAV 优先使用强 ETag 覆盖。只有秒精度 Last-Modified 时，按服务器 Date 核对至少一分钟的间隔，拒绝刚写同秒、无响应时间等无法区分并发版本的覆盖；保留另存新备份入口

复验（合成回包、临时目录、主机回环，没有真人账号或真实服务器写入）

- `bash Checks/imported_credentials.sh`：运行生产证明/合并校验，并以临时内存适配替代 Keychain、合成身份探针编译实际 AccountJar 导入/使用函数；验证离线落盘、同字节继承、错 UID、并发首用、取消、凭据变更、角色切换、旧版登录及导出不携证明
- `bash Checks/storage_locations.sh`：新权威副本不存在、篡改时旧文件仍在，恢复完整文件后才可回收；原有成组导出、目录事务和认证封装通过
- `python3 Checks/backup_recovery.py`：独立 Python/Swift 便携加密互通、拒绝篡改、回滚、多账号回复及真实回环 DAV 条件写入通过
- `python3 Checks/offline_resume.py`：实际生产权限、缓存代次、断点与崩溃尾、每观看者进度/删除通过
- iPhoneOS 27.1 SDK 对新证明、隔离探针、AccountJar、远程退出、下载管理、媒体存储、缓存条目、包格式及 DAV 实际消费者的 arm64 类型检查通过

iOS Keychain、文件提供器的授权/拔插和在设备上的离线恢复留在整机清单；本轮未操作手机或用户已缓存的媒体
