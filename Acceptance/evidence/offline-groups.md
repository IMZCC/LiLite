# 离线分集与连续播放

对照 lib/pages/download/page/view.dart。普通视频的多个缓存分 P 按稿件分组，保留单集快速入口；分集列表可以搜索、倒序、全选和分别选择暂停、继续、重试、更新字幕弹幕或删除。本机删除前显示数量，按确认时的任务代次匹配；旧勾选不会删除同 ID 重试产生的新任务。批量删除只枚举一次后台任务并只取消对应资源

离线队列可以从指定分集起播，手动上一集/下一集和播完自动续集。继续播放同时恢复最后一集和本账号的播放点，关闭观看记忆时不读写；定时停止要求停在本集时不推进队列。按源分 P 顺序恢复，旧索引没有顺序字段时使用添加时间

主机检查验证旧/新任务标识及分 P 顺序，iOS Release 已编译。真机仍需验证后台传输、断网连续播放及相同稿件重下后的删除确认。本项针对已有缓存，未将剧集或课程的播放权直接当作下载权
