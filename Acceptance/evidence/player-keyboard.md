# 外接键盘控制

核对固定版的 lib/plugin/pl_player 与 lib/pages/video/view.dart。快捷键作用在有焦点的播放器，文本框或文本编辑器开始编辑时让出焦点，Command、Control、Option 组合交给系统

空格播放/暂停，左右按设置秒数定位，上下调节播放器音量，M 静音，D 切换弹幕，F 切换支持的全屏页面，L 操作全屏锁，[ 和 ] 按当前顺序选前后集，逗号和句号从用户速率表选择，S 在全屏打开截图面板。直播不接收点播定位或倍速键。手动切集优先当前多 P，再到媒体队列或合集；主机回归检查正反顺序及首尾边界。截图面板需要用户操作才保存或分享

设备键盘焦点、系统全屏返回、不同键盘布局和原版其他组合键尚待核查。此项保留为部分移植
