# 连接错误的重试

基线 lib/http/init.dart、lib/http/retry_interceptor.dart、lib/pages/setting/models/extra_settings.dart：默认 2 次、基准间隔 500 毫秒，间隔乘本次重试序号，次数 0–8，间隔 0–1000 毫秒。原生设置从下一次请求生效，可从上游备份往返

Web API 的读取、只读评论 / 动态 / 消息 RPC、游客字幕目录与字幕文件遇到暂时的 DNS、连接或超时错误时使用该策略。重试前重新核对当前账号及服务角色，已撤销的移动授权不会继续使用。服务端已经作出响应、证书错误、任务取消均不会触发再次发送。私信发送 / 置顶 / 清未读等写入 RPC 不进入循环，点赞、投币与评论的写入也保持独立传输路径。流式视频或已有部分内容的下载继续使用各自的数据完整性检查

主机故障注入回归覆盖 500 / 1000 毫秒间隔及第 3 次成功、写请求只发一次、TLS 错误、取消、在等待中退出。没有通过真实账号制造写入。其他专用请求、真实网络切换及整个 App 的行为仍待核查
