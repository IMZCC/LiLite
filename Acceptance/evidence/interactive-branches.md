互动视频按固定 lib/pages/video/view.dart 及 controller.dart 获取 graph_version 和 edgeinfo_v2；选择时使用服务返回的 edge ID 与媒体 CID。播完只显示当前节点第一道问题的选项，不把下一道题的分支提前摊开。当前题的无效/重复条目不会吞掉其余可用选项

剧情归属整个 DetailView 播放会话。默认打开评论、切换简介、进入全屏不会取消剧情读取。对已知互动稿件，在播完时等待该节点的实际读取再决定显示选择还是沿普通队列结束；如果读取失败，可以就地重试。返回故事起点、跨稿件/切账号、服务回包晚于上一段的选择各有独立处理。画面、评论只是观察或发起选择，不复用上一条稿件的 edge_id

Checks/interactive_story.sh 运行真实 InteractiveStory，注入模拟服务控制回包顺序。覆盖主问题和次问题、无效 CID、同 ID 不同目标、终点重开、相同稿件不同账号、旧响应晚到、拒绝时清空选择。iPhoneOS SDK 定点通过，物理设备的片尾转场保留最终整包核查
