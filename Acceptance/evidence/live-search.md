# 直播间和主播搜索

从直播首页的放大镜进入原生搜索，分别按直播间和主播分页；有总量时显示计数，主播行支持打开其直播间和个人空间。解码兼容数字或字符串直播间 ID 以及命中关键词的高亮标签

固定版 lib/pages/live_search/child 分别消费 room.list / user.list 及总数。原生版使用站内已有的网页分类搜索及正常的 WBI 查询流程，使用 live_room 和 live_user 两个明确分类。匿名直接读原版移动服务时，HTTP 200 但业务返回 -400；没有将其标为可用。本地 Swift 客户端用“音乐”实际读网页服务，两个分类均成功解析 20 条，并各自取得下一页。若返回验证要求，界面显示该错误

复测入口为 PILI_LIVE_SEARCH=1 bash Checks/public_services.sh。待整体验收时复核输入与分类切换、关注账号的搜索和房间导航
