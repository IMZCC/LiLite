# 在线渐进 MP4 原生解码与回退

- 入口：普通视频页 → 当前视频没有可用 DASH 或默认使用渐进线路时。正常自动模式保留原有 AVPlayer / MediaLoader 的首帧路径；系统播放失败会在该视频服务已经返回的同一条渐进线路上尝试配置允许的拷贝或软件解码。明确设置软件解码 / 拷贝时直接解析渐进视频，不降为 AVPlayer 直接解码
- BiliAPI.playback 接受预期视频账号；PlayerModel 在索引、开播、恢复时检查账号、播放对象与线路的代数。清晰度、当前进度、播放/暂停、原选择的音轨不变；更换 CDN 重新取索引，切解码路线可共用已验证的同一来源索引。只保存内存引用，网络只向服务返回的媒体 URL 发送 Range、Referer 和 User-Agent，不向媒体请求附带账号 Cookie
- RemoteMovieMetadata 通过合法 206 分段读取文件头及 moov，包括文件尾 moov；同一实例的资源总长必须一致。LocalMovieFragments 根据真实 stsc、stsz/stz2、stco/co64、时基/关键帧和显示顺序建立虚拟音视频轨道。随后分段处理、保留原 AAC、按关键帧恢复、系统/HDR 输出、内存压力及 seek 取消复用已有原生解码线路。范围读取将相邻交错包合并，单次最多 512 KiB；不会要求把整个 MP4 下载到磁盘或内存
- 再现：WSL 运行 python3 Checks/native_decode.py。包含本机 127.0.0.1 的真实 Range HTTP 服务，输入为离线生成、没有账号信息的 HEVC 和 AV1 + AAC 单文件。AV1 样本额外使用 stz2 / co64 和尾部 moov。验证服务器每次收到 Range，实际 HTTP 返回的中段视频、音频及从样本中间截取的字节均与本地读取完全一致；将远端字节实际软件解码后，输出的完整中段帧、DTS 和 PTS 同本地转换。两个服务均没有收到整片请求；公网、真账号不参与此回归
- 此路径处理普通清晰 MP4 样本，不附加权益、不解密受保护内容。遇 HTTP 401、403、412、429 不反复切换线路试探；不解析外部 dref。索引声明的样本必须属于实际 mdat，转换段和内存有界
- 没有改写直播 HLS / FLV、动态媒体导出，或把它们计为本项已验证。真实 CDN 放行、Apple VideoToolbox 实机输出、长片功耗及后台行为留在真机验收项
