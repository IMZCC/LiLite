# 离线原生解码与跳转

- 入口：下载管理 → 已完成 → 播放。使用当前视频账号检查、已完成的下载记录、已有文件位置的播放租约；番剧等账号绑定缓存会在打开前后、本地读段及返回给播放器前重新检查归属。播放关闭会撤销监听、取消转换和字节传输。支持缓存文件迁移后的固定文件租约，不从文件名或外链另找视频
- UGC / PGC 已存视频和原声分轨：使用原有一个或多个 SIDX；无 SIDX 的 fMP4 根据 moof、tfhd、trex 和 trun 重建分段。系统、拷贝、软件路线继续按播放设置选择；切换路线保留进度和播放意图，字幕等其他缓存附件不经媒体转换
- 旧单文件渐进 MP4：从文件前部或尾部读取 moov，解析 stco/co64、stsc、stsz / stz2、stss、stts、ctts、轨道时基和编辑表。从视频关键帧划分片段，对音频保留原包，创建只含头部和原文件范围的单轨 fMP4 视图，不重新下载、不整片复制。播放请求和拖动进度按需读取样本所在字节。分辨率、编解码配置、B 帧显示顺序、音频预留和 PTS 都来自原文件
- 加密样本、外部 data reference、异常样本偏移和超限索引会被拒绝。不把杜比视界、HDR Vivid 无提示转成另一种画面；按实际可用系统路线处理。高级格式按原下载授权，兼容路径只对已取得的媒体工作
- 可重复验证：在 WSL 运行 python3 Checks/native_decode.py。实际通过 HEVC / AV1 分轨有无 SIDX 的中段解码、原 AAC 压缩数据和时间戳逐包匹配。另将两种编码及 AAC 做成 6.4 秒交错单文件，分别使用文件头和文件尾 moov。从两个单文件构建索引时实测没有读取任何 mdat 负载。验证整条视频及音频所有解码输出的字节哈希、DTS、PTS、时长同原文件；跳到非零位置重组的片段与同位置原帧逐一相等，实际经软件解码输出的中段帧数与其 PTS 一致。对篡改为加密轨和外部引用的独立样本验证拒绝
- 已用实际 iOS SDK 对本地索引、播放项、桥和解码模块做独立类型检查。FFmpeg 的主机输出使用 LGPL MPEG-2 测试编码器；iPhone 的最终输出使用 VideoToolbox H.264/HEVC，需要整机验收时测功耗、系统前后台、切换账号和外置存储
- 当前不接受跨文件媒体引用、多路同类轨或复杂编辑列表。每轨最多 512000 个样本，moov 最多 24 MiB，单关键帧区间最多 44 MiB/90 秒；正常选择“自动”时无索引/不支持的结构沿用系统原文件路径，严格指定软件或拷贝时会说明无法处理
