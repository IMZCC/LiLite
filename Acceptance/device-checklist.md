# iPhone 整体验收

安装已签名包后，可先走前三项，再按自己的使用习惯选下面的专项。用和原版相同的账号、网络及媒体比对，涉及账号写入的动作请自行决定

| 场景 | 操作 | 看什么 |
|---|---|---|
| 首页到播放 | 发现 → 推荐 → 选一条有弹幕的视频；试暂停、拖动、横屏，再返回列表 | 声音和画面同时开始；弹幕随播放暂停，跳转后跟随目标时间；回首页仍在原列表位置 |
| 长视频与分 P | 观看非第一 P 后退出，再从普通入口和一个带时间的分享链接分别打开；切换音轨、清晰度和备选线路 | 普通入口可决定是否继续上次分 P，明确指定的分享起点优先；切换后声画与进度一致 |
| 字幕与弹幕 | 找一条有字幕的视频，调字号、双语、时间偏移；从“文件”导入字幕；点选一条弹幕后收起 | 字幕排版、动画与拖动同步；命中弹幕时停在所点位置，结束选择后继续；过滤只作用于命中的类别 |
| 搜索与社区 | 搜索普通词和 BV 链接，切综合/用户/直播等分类；打开动态、专栏、帖子及二级评论 | 资源进入正确页面，筛选、折叠、楼层定位、图片浏览及返回后的位置可用 |
| 分类与失败重试 | 在搜索的不同分类各翻到第二页，来回切换；推荐或话题已有列表后断网刷新，再恢复网络重试 | 分类保留各自列表、筛选和位置；重试刷新第一页，加载更多失败重试原来那一页 |
| 账号与资料库 | 有需要时登录；设不同的推荐与观看账号；打开收藏夹、稍后再看、历史、空间和收件箱；切账号 | 各列表属于选择的账号，旧页面不展示上一人的条目；账户授权不足时有重新授权/官网入口 |
| 原生登录与设备 | 自选扫码、密码或短信登录，按服务提示完成人工/手机验证；查看登录设备；退出页面后再返回 | 原生流程取得网页和移动授权，登录设备为真实列表；取消和中途切账号不误保存，重新授权仍属于所选 UID |
| 影视、课程与听视频 | 用一集有权观看的番剧或试看课程，切目录/选集；从视频启动听视频、切前后项、显示歌词（如有） | 目录和播放器是同一集；未获准的内容保持受限；队列顺序、播放位置及锁屏控制对应当前条目 |
| 直播 | 选择正在开播的房间，切清晰度/线路/仅音频，查看聊天、在线人数、贡献榜、SC 和表情包 | 切换不换房间或聊天身份；普通表情进入草稿，关闭不会发送；转后台再回来状态正确 |
| 离线 | 缓存有权下载的一条多 P 视频，暂停后继续；缓存完成后断网，播放并拖动进度 | 进度从已下载位置继续，离线可读音视频及随包保存的字幕和弹幕；换号不能误播受限的另一人缓存 |
| 旧式视频流 | 如有只提供 durl 的合法单段/多段 MP4 或 FLV 视频，在线播放并跨段拖动，再缓存后断网播放 | 所有段落共用完整进度，跨段有声有画，原有字幕与弹幕同步 |
| 系统集成 | 锁屏、控制中心、拔耳机、切蓝牙、来电中断、系统画中画、横竖屏，若有外接键盘试播放快捷键 | 只有当前媒体响应按键；手动暂停不会被来电结束或回前台错误恢复；画中画回到同一播放器 |
| 投屏 | 打开同一网络下的 AirPlay 或 DLNA 接收器，有需要时输入电视的设备描述地址；投屏再交回手机 | 选中设备能播放并响应暂停/定位；交回手机时进度正确。开发签名的发现范围见 [投屏说明](evidence/personal-device-signing.md) |
| 设置与数据 | 修改主题/导航和一个播放器偏好，导出设置；修改后从刚导出的文件恢复 | 恢复前可预览，选择的偏好生效，登录账号不因普通设置恢复而丢失 |
| Liquid Glass | 在 iOS 26 及以上滚动首页、切底部栏目、进入全屏；试系统“降低透明度”和深浅外观 | 导航、搜索和悬浮播放控件使用系统玻璃，触控仍有效；降低透明度后清楚可读，旧系统正常使用兼容样式 |
| 系统导航与自定义 | 重选当前“发现”回顶/刷新；切栏目再返回；调整导航顺序、侧栏图标及紧凑/动画/收起配置 | 默认系统导航和独立搜索保留，切换保持页面；明确自定义配置生效，拒绝跳转时不误刷新 |
| iOS 文件与照片 | 长按图片或实况照片，在原生分享、相册、文件目录间选择；退出后再打开所选目录 | 文件内容、实况配对、系统授权和拒绝后的处理都正确，重名时不会覆盖其他文件 |

如遇问题，记录页面、资源编号、账号角色（无需提供账号）、网络类型、系统版本、实际与预期行为；无需发 Cookie、令牌、密码或签名文件
